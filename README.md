# Editor（编辑器）

一个用于体验文件编辑工作流的本地网页演示。浏览器界面通过仅监听本机回环地址的后端，读取和保存演示目录中的 UTF-8 文本、Markdown 文件；支持标签页、可调整的双栏、内置文件处理插件，以及带引用和聚焦范围的模拟助手。

本演示用于讨论交互与界面方向，不代表最终产品方案。[demo.md](demo.md) 保留了演示目标与验收要求。

界面采用简约风格，文字聚焦操作、状态和必要提示，避免重复说明与装饰性文案。

## 运行

需要 **Node.js 20 或更新版本**，不需要模型账号、密钥或第三方依赖。Windows、macOS 和 Linux 均可使用已安装的 Node.js 运行。

在项目目录执行：

~~~bash
npm start
~~~

在本机浏览器打开终端打印的**完整地址**。地址包含本次运行生成的随机会话令牌，请勿分享；重启服务后需要使用新打印的地址。保持终端运行，按 `Ctrl+C` 停止服务。

默认地址使用 `127.0.0.1:4173`。如果端口被占用，可设置 `PORT` 后重新启动，例如 PowerShell 中：

~~~powershell
$env:PORT = "4174"
npm start
~~~

页面和本地接口均由 Node.js 提供；前端采用原生 JavaScript 和 CSS，没有构建步骤。此选型方便离线体验、降低演示依赖，也意味着编辑器和 Markdown 渲染能力仍然比较基础。

## 体验

1. 首次启动时，`samples/` 中的两份虚构样例会复制到 `local-data/`；已有副本不会在重启时被覆盖。`local-data/` 已被 Git 忽略。
2. 左侧导航提供“工作空间”“插件”和“设置”。在工作空间的标签栏点击“文件”打开文档；切换标签会保留各自的编辑内容，关闭有未保存更改的标签或离开页面时会提示。
3. 点击标签栏右侧的“分栏”，可以拖动标签在两栏间移动，也可拖动分隔线调整宽度；标签获得焦点后可用 `Ctrl+Shift+方向键` 移动，分隔线获得焦点后可用方向键调整。目标栏已打开同名文件时不会移动或覆盖，请先处理该标签。收起分栏会保留隐藏区域的标签和草稿。
4. “插件”列出实际启用的内置 Markdown 和纯文本处理器：前者提供基础安全预览与标题区块，后者提供段落区块。暂不支持 Python 文件、语法高亮或安装第三方插件。Markdown 预览不是完整实现；原始 HTML 按文本显示，图片不会自动加载。
5. “设置”提供简体中文、English 和三种主题颜色，选择保存在当前浏览器的本地站点存储中；地址或端口变化时需重新设置。文件内容不会写入设置。
6. 模拟助手的“关注”始终是当前活动标签；“引用”可加入磁盘或当前编辑内容的只读快照，并展开查看。快照不会自动同步，需更新时可移除后重新添加。“聚焦”可选取内置插件识别的区块，指定为修改目标或参考片段。聚焦显示的内容是编辑器当前文本的精确切片，内部统一以 LF 表示换行；聚焦来源变化或关闭后需重新选择。
7. 输入请求后查看**模拟**建议与差异，再决定是否应用。选择“修改目标”时，建议只作用于该区块；“参考片段”不会被修改。应用后仍需手动保存。切换标签、修改原文或上下文后，旧建议不能误应用。
8. 如需体验其他文件，可自行将 UTF-8 `.txt` 或 `.md` 文件放在 `local-data/` 顶层，再通过“文件”菜单刷新列表。演示不会浏览其他目录，也不支持子目录或其他扩展名。

模拟助手只在浏览器中按固定规则处理：“添加标题”“整理空行”和“摘要”生成示例修改；“插入参考”会优先原样使用聚焦的参考片段，否则使用第一份引用快照。其他请求会作为模拟建议标记追加。规则不会理解或总结引用内容，不连接真实模型，也不会上传文档或对话。生成前后内容均限于不超过 4 万字符且不超过 400 行。

## 文件与安全边界

- 单个文件上限为 2 MB；支持有效的 UTF-8 和 UTF-8 BOM，保存时保留原有的统一 LF、CRLF 或 CR 换行。原文件没有换行时，新输入的换行使用 LF。含混合换行的文件只能查看，非 UTF-8、含二进制空字符或过大的文件无法打开，避免不安全的转换。
- 打开时记录文件内容的版本；保存时若发现其他编辑区或外部程序已修改文件，会阻止覆盖并保留当前编辑。可先复制当前未保存内容，关闭冲突的标签并确认丢弃旧编辑，再从“文件”菜单重新打开磁盘版本。
- 后端只监听 `127.0.0.1`；接口要求随机会话令牌并校验请求主机和浏览器来源，不提供跨域访问。文件名、路径、文件类型和链接会在后端校验，访问限制在本地演示目录顶层；Markdown 和模拟建议不会被当作 HTML 或脚本执行。
- 这是本机单用户演示，不是隔离其他同权限本地进程的安全沙箱。保存前会再次检查版本，但外部程序仍可能在最后一次检查与替换之间修改文件；不同文件系统对替换、权限及元数据的行为也可能不同。请勿依赖此演示处理需要严格并发保护或完整元数据保留的重要文件。
- 不支持真实模型接入、任意目录浏览、文件创建或删除、完整权限系统、多人协作和公开部署。

## 后续产品方向

以下仍是规划，不代表演示已经实现：

- 浏览用户授权范围内的文件，按类型提供合适的视图；继续完善多窗口、编码、换行和外部修改冲突的处理。
- 支持用户配置模型和选择发送内容；接入外部服务时说明数据传输，在用户检查差异并确认后才应用修改，凭据保留在安全的本地存储中。
- 继续限制本地后端的访问范围，并防范路径穿越、链接、跨站请求、DNS 重绑定和未授权访问。若未来允许对外开放，需要另行设计认证与授权。
- 将文件、模型输出和外部内容视为不可信数据，不直接作为代码、命令或未经安全处理的 HTML 执行。

## 验证

~~~bash
npm test
~~~

自动测试覆盖本地接口鉴权、路径限制、编码与换行、保存冲突、插件区块范围和聚焦修改等行为。符号链接相关测试需要操作系统允许创建测试链接；不允许时该项会显示为跳过。
