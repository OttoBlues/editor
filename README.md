# Editor

一个规划中的文件查看与编辑项目：通过网页界面访问本地部署的后端内核，按文件类型提供合适的查看和编辑方式，支持多个编辑窗口，并可与用户配置的 AI 模型协作修改内容。

## 项目状态

目前处于项目准备阶段，仓库尚无可运行的前端或后端。技术栈、支持的文件类型、模型接入方式及安装运行命令将在实现时确定并补充。

首个演示的目标、建议范围和验收方式见 [demo.md](demo.md)。演示用于验证框架和界面风格，其选择不自动成为最终产品方案。

## 产品方向

以下是计划中的方向，不代表已经实现：

- 浏览用户授权范围内的文件，为不同文件类型提供合适的视图和编辑方式，并在无法识别或处理时给出明确提示。
- 同时管理多个编辑窗口，维护各自的编辑与未保存状态；保存时关注编码、换行、外部修改和冲突，避免静默丢失或覆盖内容，无法无损保存时先告知用户。
- 将模型接入、对话和编辑操作适当分离。由用户选择发送给模型的内容；使用外部服务时说明数据将离开本机。模型建议应提供可检查的差异，由用户决定是否应用和保存；删除、覆盖等破坏性操作需要明确确认。
- 本地后端默认只监听回环地址，限制文件访问范围，并防范路径穿越、符号链接、跨站请求、DNS 重绑定和未授权访问。若未来支持对外开放，应明确设计认证、授权与用户配置。
- 将文件、模型输出和外部内容视为不可信数据，不直接作为代码、命令或未经安全处理的 HTML 执行。凭据不写入前端、源码或日志；敏感配置、用户文件和运行数据不纳入公开仓库。
