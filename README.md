# Editor（编辑器）

一个用于体验文件编辑工作流的本地网页演示。浏览器界面通过仅监听本机回环地址的后端，读取和保存演示目录中的 UTF-8 文本、Markdown 文件；支持标签页、可调整的双栏、内置文件处理插件，以及带引用、关注文件和聚焦范围的“智能编辑”演示。

本演示用于讨论交互与界面方向，不代表最终产品方案。[demo.md](demo.md) 保留了演示目标与验收要求。

界面采用简约风格，文字聚焦操作、状态和必要提示，避免重复说明与装饰性文案。

## 运行

需要 **Node.js 20 或更新版本**，不需要模型账号、密钥或第三方依赖。Windows、macOS 和 Linux 均可使用已安装的 Node.js 运行。

在项目目录执行：

~~~bash
npm start
~~~

在本机浏览器打开终端打印的**完整地址**。地址包含本次运行生成的随机会话令牌，请勿分享；重启服务后需要使用新打印的地址。保持终端运行，按 `Ctrl+C` 停止服务。

默认地址使用 `127.0.0.1:4173`。如果端口被占用，可设置 `PORT` 后重新启动，例如 PowerShell 中：

~~~powershell
$env:PORT = "4174"
npm start
~~~

页面和本地接口均由 Node.js 提供；前端采用原生 JavaScript 和 CSS，没有构建步骤。此选型方便离线体验、降低演示依赖，也意味着编辑器和 Markdown 渲染能力仍然比较基础。

## 体验

1. 首次启动时，`samples/` 中的两份虚构样例会复制到 `local-data/`；已有副本不会在重启时被覆盖。`local-data/` 已被 Git 忽略。
2. 左侧导航提供“工作空间”“插件”“模型”和“设置”。标签栏最后一个标签后有“+”，每次点击打开一个独立空标签页，提示“将文件拖入此区域进行编辑”。可拖入或点击选择 `.md` / `.txt` 文件，也可展开空标签页中的“演示目录中的文件”。多个文件会分别打开；第一个文件填入当前空标签，其他已有标签不被覆盖。切换标签会保留各自的编辑内容，关闭有未保存更改的标签或离开页面时会提示。
3. 点击标签栏右侧的分栏 SVG 图标按钮（悬停显示操作名称，再次点击收起分栏），可以拖动标签（包括空标签）在两栏间移动，也可拖动分隔线调整宽度；标签获得焦点后可用 `Ctrl+Shift+方向键` 移动，分隔线获得焦点后可用方向键调整。目标栏已打开同一演示目录文件时不会移动或覆盖，请先处理该标签。浏览器拖入的同名文件作为独立副本处理，不会误绑定演示目录的同名文件。收起分栏会保留隐藏区域的标签和草稿。
4. 左侧“插件”使用拼图块图标，列出实际启用的内置 Markdown 和纯文本处理器。点击插件进入配置页面，可分别设置“按文档结构”（默认）或“当前选取”的聚焦方式，设置自动保存在当前浏览器中，刷新后仍保留。Markdown 提供基础安全预览及结构区块，纯文本提供段落区块；智能编辑中的添加按钮按插件的 capabilities 分别启用引用、关注和聚焦，未声明的能力默认禁用。暂不支持 Python 文件、语法高亮或安装第三方插件。Markdown 预览支持带表头和对齐的管道表格、嵌套粗体与行内代码、标题、列表、引用、围栏及缩进代码和显式换行；宽表可在表格内横向滚动。包含竖线的普通公式不会单独被识别成表格。预览与聚焦共用结构识别，但预览不是完整 Markdown 实现，Mermaid 仍显示源码；原始 HTML 按文本显示，图片不会自动加载。本地路径及其他不支持的链接只显示可读标题，悬停可查看目标文本，不访问本地路径。
5. “设置”提供简体中文、English，以及浅色（日间）和深色（夜间）两种主题。主题切换即时应用于编辑器、预览、侧栏、卡片和提示，并保存在当前浏览器的本地站点存储中，刷新后仍保留；地址或端口变化时需重新设置。首次使用及旧版颜色设置默认采用浅色主题，原有语言偏好保留。文件内容不会写入设置。
6. 右侧“智能编辑”的“引用”“关注”“聚焦”标题前分别显示链环、眼睛和取景框 SVG 图标，标题右侧的“+”添加当前文件的对应内容；编辑工具栏不再放置这些按钮。已添加的引用、关注不会重复添加，可用卡片右侧“×”取消。卡片只显示文件名，点击会切回工作空间并定位来源标签（包括其他分栏或隐藏分栏）。“引用”保存添加时的只读快照，更新时取消后重新添加；“关注”决定允许编辑的文件，跟随来源内容更新，切换标签不改变已关注文件。只读文件不能加入关注，添加聚焦也不会自动关注。关闭文件会移除对应关注和聚焦，独立引用快照继续保留。点击已关闭文件的引用卡片时，演示目录文件重新读取磁盘版本，拖入文件从引用快照恢复为可编辑副本；均不覆盖其他标签的草稿，也不改变原引用快照。
7. 点击“聚焦”标题右侧的“+”，在当前文件右侧展开聚焦栏。在正文点选一个或多个区块，在“说明”输入框填写共同要求（必填，最多 2000 字符），按 Enter 或点击框内发送按钮即可创建聚焦；Shift+Enter 换行，输入法确认候选字不会误发送。选区和说明始终同屏，没有分步、来源、划分方式或用途控件。默认“按文档结构”聚合划分，未选区块可直接点击，选中后淡色高亮，再次点击取消；也可用 Tab 定位后按空格或 Enter 切换。需要手选范围时，在对应插件配置中改为“当前选取”，回到文件选择文字并点击“加入当前选取”，可重复添加不重叠的范围，用“查看已选区块”核对和取消。每组生成一张只显示文件名的卡片，点击会定位来源并同时显示所选范围和说明，铅笔按钮可编辑；右侧“×”移除整组。关闭聚焦栏会放弃未确认的草稿，编辑已有聚焦时不会更改原记录。
8. 在“编辑要求”输入全局请求，按 Enter 或点击框内发送按钮生成建议，Shift+Enter 换行；已关注文件具有聚焦说明时，可留空全局请求。“模型回复”保留本次页面会话的请求和明确标注为演示的回复；“修改内容追踪”按批次、文件显示可展开的差异，以及待应用、失效、已应用未保存、已保存等状态。只有关注文件可能被修改，与当前显示的标签无关；全局请求作用于所有关注文件，有聚焦时以各组说明限定范围，只有聚焦说明而无全局请求时跳过没有聚焦的文件。点击“应用到关注文件”前会验证整批目标和上下文，应用后仍需手动保存。请求、目标原文或相关上下文变动会使旧建议失效；回复、差异历史、引用、关注和聚焦不会跨刷新保留。
9. 拖入或选择的外部文件只在浏览器内读取和编辑，使用“保存副本”下载修改结果，不覆盖原文件，也不写入演示目录。演示目录中的文件仍通过后端“保存”并检测版本冲突。如需体验后端保存，可自行将 UTF-8 .txt 或 .md 文件放在 local-data/ 顶层，再从空标签页的演示文件列表刷新并打开。演示不会浏览其他目录，也不支持子目录或其他扩展名。

10. “模型”目前提供配置页面壳子，可填写显示名称、服务地址与模型标识，切换页面时保留草稿，刷新后清空。它不会建立连接、发送请求或保存凭据，也不改变智能编辑使用的本地模拟；连接、凭据管理与实际模型调用留待工程化设计。

聚焦组保留每个区块的精确原文切片和创建时的文档快照，不把非连续区块之间的内容扩入范围。例如“标题＋正文 → 列表 → 流程说明 → 流程图”会成为四个区块，可以共同选中并填写一条说明。标题组合其后连续正文，遇到列表、图表、代码或下一个标题即结束；列表包含相邻条目、嵌套条目和续行。流程图识别顶层 mermaid 围栏，表格识别带分隔行的管道表格，代码支持围栏和缩进代码块，引用段落和分隔线也单独成块。未识别语法作为普通文本，开头空白归入第一块，区块之间及结尾空白归入前一块，纯空白文件也可选择；区块按顺序拼接可逐字还原全文，空文件不生成虚假范围。这不是完整 Markdown 解析器，复杂嵌套可在插件配置中启用“当前选取”；区块视图安全显示源码，不执行图表代码。结构视图每页最多提供 200 个原始区块，翻页保留选择和说明，总数包含其他页；手选范围跨页时保持完整，手选与结构区块混用时，其余原文仍可选择。聚焦栏在当前编辑栏内部的正文右侧独立占位；编辑栏宽度不足 620 像素时移到正文下方，正文与聚焦栏分别滚动。点击智能编辑区域不会收起聚焦栏；再次点击聚焦“+”、栏内关闭按钮或 Escape 可关闭，切换文件或页面也会关闭，文件编辑内容不受影响。

每个聚焦组携带多个范围和一条共同说明。可编辑文件的聚焦限定修改范围，但文件必须先加入关注；只读文件的聚焦自动作为参考片段，无法成为修改目标，也无需手动选择用途。同一文件的修改范围不能重叠，原文变化后须重新选区确认；点击与当前内容不一致的聚焦卡片只打开文件，不套用旧位置。

“智能编辑”当前只在浏览器内按固定规则模拟，尚未连接真实模型，也不具备对任意批注的语义理解。每组按共同说明匹配规则：“添加标题”和“摘要”只在组内首个区块添加一次，“整理空行”处理组内各区块，范围外原文保持不变。说明包含“合并”“整合”且选中多个区块时，仅将所选原文按文档顺序拼接到首个区块并清除其他被选原位置，中间未选内容和空白逐字保留；这不是语义重写或智能去重。“插入参考”优先原样使用只读文件的聚焦片段，否则使用明确添加的引用快照；关注文件不会自动成为参考来源。多个来源按卡片顺序以空行分隔，组内按原文顺序组合；参考片段的说明仍保留在上下文中，但固定规则只使用其文本。参考插入及其他请求的模拟标记只在组内最后一个区块追加一次。文档、聚焦说明和请求不会上传或存入设置，设置只保存语言、主题和各插件的聚焦方式。单份文件生成前后均限于不超过 4 万字符且不超过 400 行。

## 文件与安全边界

- 单个文件上限为 2 MB；支持有效的 UTF-8 和 UTF-8 BOM，保存时保留原有的统一 LF、CRLF 或 CR 换行。原文件没有换行时，新输入的换行使用 LF。含混合换行的文件只能查看，非 UTF-8、含二进制空字符或过大的文件无法打开，避免不安全的转换。
- 从演示目录打开时记录文件内容的版本；保存时若发现其他编辑区或外部程序已修改文件，会阻止覆盖并保留当前编辑。可先复制当前未保存内容，关闭冲突的标签并确认丢弃旧编辑，再从空标签页的演示文件列表重新打开磁盘版本。浏览器拖入文件使用下载副本，不参与后端版本检查；下载发起后仍需确认浏览器实际保存完成。
- 后端只监听 `127.0.0.1`；接口要求随机会话令牌并校验请求主机和浏览器来源，不提供跨域访问。文件名、路径、文件类型和链接会在后端校验，访问限制在本地演示目录顶层；Markdown 和模拟建议不会被当作 HTML 或脚本执行。
- 这是本机单用户演示，不是隔离其他同权限本地进程的安全沙箱。保存前会再次检查版本，但外部程序仍可能在最后一次检查与替换之间修改文件；不同文件系统对替换、权限及元数据的行为也可能不同。请勿依赖此演示处理需要严格并发保护或完整元数据保留的重要文件。
- 不支持真实模型接入、任意目录浏览、后端文件创建或删除、原位覆盖拖入文件、完整权限系统、多人协作和公开部署。

## 后续产品方向

以下仍是规划，不代表演示已经实现：

- 浏览用户授权范围内的文件，按类型提供合适的视图；继续完善多窗口、编码、换行和外部修改冲突的处理。
- 支持用户配置模型和选择发送内容；接入外部服务时说明数据传输，在用户检查差异并确认后才应用修改，凭据保留在安全的本地存储中。
- 继续限制本地后端的访问范围，并防范路径穿越、链接、跨站请求、DNS 重绑定和未授权访问。若未来允许对外开放，需要另行设计认证与授权。
- 将文件、模型输出和外部内容视为不可信数据，不直接作为代码、命令或未经安全处理的 HTML 执行。
