# Editor

一个规划中的文件查看与编辑项目：通过网页界面访问本地部署的后端内核，按文件类型提供合适的查看和编辑方式，支持多个编辑窗口，并可与用户配置的 AI 模型协作修改内容。

## 项目状态

目前处于项目准备阶段，仓库尚无可运行的前端或后端。技术栈、支持的文件类型、模型接入方式及安装运行命令将在实现时确定并补充。

计划重点：

- 浏览本地授权范围内的文件，并为不同文件类型提供合适的视图。
- 同时管理多个编辑窗口，保护未保存的修改并处理文件冲突。
- 由用户选择模型及发送内容，检查 AI 提议的修改后再应用。
- 将敏感配置、用户文件和运行数据保留在本地，不纳入公开仓库。

## 协作

开发约定和安全边界见 [AGENTS.md](AGENTS.md)。每次完成一项自洽的改动，应检查暂存内容并创建相应的 Git 提交。公开源码、必要配置、文档和项目声明时，避免提交凭据、个人数据或临时文件。

`.gitignore` 包含常见本地配置、用户数据、缓存和构建产物规则；它不能代替提交前审查。若确需版本化某种被忽略的文件，应先确认内容可以公开并调整规则。

## 许可证
