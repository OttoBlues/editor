# Editor（编辑器）

一个用于体验文件编辑工作流的本地网页演示。浏览器界面通过仅监听本机回环地址的后端，读取和保存演示目录中的 UTF-8 文本、Markdown 文件；支持标签页、可调整的双栏、内置文件处理插件，以及带引用和聚焦范围的模拟助手。

本演示用于讨论交互与界面方向，不代表最终产品方案。[demo.md](demo.md) 保留了演示目标与验收要求。

界面采用简约风格，文字聚焦操作、状态和必要提示，避免重复说明与装饰性文案。

## 运行

需要 **Node.js 20 或更新版本**，不需要模型账号、密钥或第三方依赖。Windows、macOS 和 Linux 均可使用已安装的 Node.js 运行。

在项目目录执行：

~~~bash
npm start
~~~

在本机浏览器打开终端打印的**完整地址**。地址包含本次运行生成的随机会话令牌，请勿分享；重启服务后需要使用新打印的地址。保持终端运行，按 `Ctrl+C` 停止服务。

默认地址使用 `127.0.0.1:4173`。如果端口被占用，可设置 `PORT` 后重新启动，例如 PowerShell 中：

~~~powershell
$env:PORT = "4174"
npm start
~~~

页面和本地接口均由 Node.js 提供；前端采用原生 JavaScript 和 CSS，没有构建步骤。此选型方便离线体验、降低演示依赖，也意味着编辑器和 Markdown 渲染能力仍然比较基础。

## 体验

1. 首次启动时，`samples/` 中的两份虚构样例会复制到 `local-data/`；已有副本不会在重启时被覆盖。`local-data/` 已被 Git 忽略。
2. 左侧导航提供“工作空间”“插件”和“设置”。标签栏最后一个标签后有“+”，每次点击打开一个独立空标签页，提示“将文件拖入此区域进行编辑”。可拖入或点击选择 `.md` / `.txt` 文件，也可展开空标签页中的“演示目录中的文件”。多个文件会分别打开；第一个文件填入当前空标签，其他已有标签不被覆盖。切换标签会保留各自的编辑内容，关闭有未保存更改的标签或离开页面时会提示。
3. 点击标签栏右侧的“分栏”，可以拖动标签（包括空标签）在两栏间移动，也可拖动分隔线调整宽度；标签获得焦点后可用 `Ctrl+Shift+方向键` 移动，分隔线获得焦点后可用方向键调整。目标栏已打开同一演示目录文件时不会移动或覆盖，请先处理该标签。浏览器拖入的同名文件作为独立副本处理，不会误绑定演示目录的同名文件。收起分栏会保留隐藏区域的标签和草稿。
4. “插件”列出实际启用的内置 Markdown 和纯文本处理器：前者提供基础安全预览及结构区块，后者提供段落区块。工具栏按插件的 `capabilities` 分别启用引用、关注和聚焦 SVG 图标，未声明的能力默认禁用。暂不支持 Python 文件、语法高亮或安装第三方插件。Markdown 预览不是完整实现；原始 HTML 按文本显示，图片不会自动加载。
5. “设置”提供简体中文、English，以及浅色（日间）和深色（夜间）两种主题。主题切换即时应用于编辑器、预览、侧栏、卡片和提示，并保存在当前浏览器的本地站点存储中，刷新后仍保留；地址或端口变化时需重新设置。首次使用及旧版颜色设置默认采用浅色主题，原有语言偏好保留。文件内容不会写入设置。
6. 文件编辑工具栏用链环和眼睛两个 SVG 图标分别切换“引用”和“关注”，第一次点击添加并高亮，再次点击取消；悬停或辅助阅读可查看当前操作。右侧引用、关注、聚焦卡片只显示文件名，点击卡片会切回工作空间并定位到来源标签（包括其他分栏或隐藏分栏）；右侧“×”单独取消该项，不触发跳转。“引用”保存添加时的只读快照，需更新时取消后重新添加；“关注”跟随来源文件的编辑内容更新，切换标签不改变已关注文件。关闭文件会移除对应关注和聚焦，独立引用快照继续保留。点击已关闭文件的引用卡片时，演示目录文件重新读取磁盘版本，拖入文件从保留的引用快照恢复为可编辑副本；均不覆盖其他标签的草稿，也不改变原引用快照。
7. 点击工具栏的取景框图标，在当前文件左侧展开聚焦栏，分两步创建聚焦：先在文件内容区直接点选区块，再填写这一组区块共同的“聚焦／改动说明”（必填，最多 2000 字符）。区块按正文宽度统一对齐，左侧用勾选标记表示状态；选中后显示淡色背景和细竖线，再次点击取消，也可通过键盘 Tab 定位后按空格或 Enter 切换。聚焦栏负责选择来源和划分方式，正文保留完整原文，不再用整圈虚实线框分割内容。Markdown 支持按标题区块、文本段落、Mermaid 流程图、表格或代码块划分；纯文本支持段落。多个区块可以组成一项合并、重新整合等共同要求，切换划分方式和翻页保留已选区块，切换来源或原文变化则清空待确认的选择。两种文件都支持“当前选取”：在编辑区选中文字后点击“加入当前选取”，重复操作可加入多个不重叠的范围；“查看已选区块”可核对和取消，已有文字选择也可直接带入聚焦。第二步可回到上一步调整区块，说明草稿保留；取消不会创建或修改已保存聚焦。每组生成一张只显示文件名的卡片，点击会定位来源文件，在内容区显示这组精确范围并打开共同说明；铅笔按钮编辑，右侧“×”移除整组。切换标签、修改原文或引用 / 关注 / 聚焦（含说明）后，旧建议不能误应用。应用后仍需手动保存。
8. 拖入或选择的外部文件只在浏览器内读取和编辑，使用“保存副本”下载修改结果，不覆盖原文件，也不写入演示目录。演示目录中的文件仍通过后端“保存”并检测版本冲突。如需体验后端保存，可自行将 UTF-8 `.txt` 或 `.md` 文件放在 `local-data/` 顶层，再从空标签页的演示文件列表刷新并打开。演示不会浏览其他目录，也不支持子目录或其他扩展名。

聚焦组保留每个区块的精确原文切片和创建时的文档快照，不把非连续区块之间的内容扩入范围。标题区块从该标题延伸至下一标题之前；流程图识别顶层 `mermaid` 围栏代码块，表格识别带分隔行的管道表格，代码支持围栏和缩进代码块。此分块器不是完整 Markdown 解析器，复杂嵌套请使用“当前选取”核对范围；区块视图以安全文本方式显示完整源码，不执行图表代码。每页最多提供 200 个候选区块，其他位置已选的区块仍可见；未匹配内容显示为普通原文。切换划分方式时，与已选范围重叠的候选区块暂不显示，先取消原区块即可重新选择更大的范围。聚焦栏位于当前编辑栏内部，桌面下在正文左侧独立占位，不覆盖正文或右侧助手；按实际编辑栏宽度适配，小于 620 像素时排在正文下方。聚焦栏和正文分别滚动，底部步骤按钮固定可见。点击助手区域不会收起聚焦栏；工具栏取景框图标、栏内关闭按钮或 Escape 可收起并放弃未确认的聚焦草稿，切换文件或页面也会收起，文件编辑内容不受影响。

每个聚焦组同时携带多个范围、一个用途和一条共同说明，供助手判断这组内容的处理方向。可编辑文件默认用作修改目标；只读文件和引用快照仅能作为参考片段，选择引用时内容区会标明只读快照来源。同一来源的修改目标不能重叠，原文变化后须重新确认范围；点击与当前文件内容不同的快照时只打开文件，不套用旧位置。模拟建议只修改当前标签的聚焦目标，其他文件的目标需要切回对应标签处理。

模拟助手只在浏览器中按固定规则处理。有修改目标时，每组按共同说明匹配规则，可以不填写全局修改要求；没有修改目标时使用全局请求。“添加标题”和“摘要”只在组内首个区块添加一次，“整理空行”整理组内各个区块，范围外原文保持不变。多区块说明包含“合并”“整合”时，演示仅将所选原文按文档顺序以空行拼接到首个区块，清除其余被选中的原位置，中间未选的内容和空白逐字保留；这不是语义重写或智能去重。“插入参考”优先原样使用聚焦的参考片段，否则使用引用快照；两者都没有时，使用已关注的其他打开文件。多个来源按卡片顺序以空行分隔，每个参考组内部按原文顺序组合，不带入未选内容。参考插入及其他请求的模拟标记只在组内最后一个区块追加一次。当前没有真实模型，也不具备对任意批注的语义理解；参考片段的说明随聚焦上下文传入，但固定规则只原样使用其文本。文档、聚焦说明和对话不会上传或存入设置。生成前后内容均限于不超过 4 万字符且不超过 400 行。

## 文件与安全边界

- 单个文件上限为 2 MB；支持有效的 UTF-8 和 UTF-8 BOM，保存时保留原有的统一 LF、CRLF 或 CR 换行。原文件没有换行时，新输入的换行使用 LF。含混合换行的文件只能查看，非 UTF-8、含二进制空字符或过大的文件无法打开，避免不安全的转换。
- 从演示目录打开时记录文件内容的版本；保存时若发现其他编辑区或外部程序已修改文件，会阻止覆盖并保留当前编辑。可先复制当前未保存内容，关闭冲突的标签并确认丢弃旧编辑，再从空标签页的演示文件列表重新打开磁盘版本。浏览器拖入文件使用下载副本，不参与后端版本检查；下载发起后仍需确认浏览器实际保存完成。
- 后端只监听 `127.0.0.1`；接口要求随机会话令牌并校验请求主机和浏览器来源，不提供跨域访问。文件名、路径、文件类型和链接会在后端校验，访问限制在本地演示目录顶层；Markdown 和模拟建议不会被当作 HTML 或脚本执行。
- 这是本机单用户演示，不是隔离其他同权限本地进程的安全沙箱。保存前会再次检查版本，但外部程序仍可能在最后一次检查与替换之间修改文件；不同文件系统对替换、权限及元数据的行为也可能不同。请勿依赖此演示处理需要严格并发保护或完整元数据保留的重要文件。
- 不支持真实模型接入、任意目录浏览、后端文件创建或删除、原位覆盖拖入文件、完整权限系统、多人协作和公开部署。

## 后续产品方向

以下仍是规划，不代表演示已经实现：

- 浏览用户授权范围内的文件，按类型提供合适的视图；继续完善多窗口、编码、换行和外部修改冲突的处理。
- 支持用户配置模型和选择发送内容；接入外部服务时说明数据传输，在用户检查差异并确认后才应用修改，凭据保留在安全的本地存储中。
- 继续限制本地后端的访问范围，并防范路径穿越、链接、跨站请求、DNS 重绑定和未授权访问。若未来允许对外开放，需要另行设计认证与授权。
- 将文件、模型输出和外部内容视为不可信数据，不直接作为代码、命令或未经安全处理的 HTML 执行。

## 验证

~~~bash
npm test
~~~

自动测试覆盖本地接口鉴权、路径限制、编码与换行、保存冲突、拖入文件解码与导出、插件能力声明、Markdown 分类区块与分页，以及聚焦组共用说明、多个组独立修改、精确合并、未选区间保留、过期和重叠范围拒绝等行为。符号链接相关测试需要操作系统允许创建测试链接；不允许时该项会显示为跳过。
