# 让想法，慢慢成形

欢迎来到编辑器演示。这里是一个安静的工作空间，适合记录想法、整理文字，也适合试试并排编辑。

## 从这里开始

- 点击标签栏末尾的「+」，将文件拖入空标签页，或展开演示文件列表打开。
- 修改文字后，点击「保存」写入演示目录；拖入的文件通过「保存副本」下载。
- 切换到「预览」，看看 Markdown 标题、列表和表格的排版效果。
- 标签栏右端的分栏图标可切换单栏／双栏；「模型」页面可预览配置界面，当前尚未接入真实模型。

## 一个小提示

右侧的 **智能编辑** 目前使用本地规则模拟。先用「关注」右侧的「+」添加允许修改的文件，再输入「编辑要求」，按 Enter 或点击框内发送按钮生成建议，Shift+Enter 换行。查看「模型回复」和「修改内容追踪」中的差异后，再决定是否应用；应用后仍需手动保存。

「引用」「关注」「聚焦」标题旁的「+」都针对当前文件。引用保留添加时的只读快照，关注决定修改目标，切换标签不会改变它们。点击文件名卡片可返回对应标签，点击「×」取消。

点击「聚焦」右侧的「+」，在文件右侧展开聚焦栏。默认按文档结构聚合划分：标题与正文、完整列表、独立说明段落、流程图等各自成块，其他文字和空白也包含在可选范围内。点击正文区块或勾选标记，可多选并填写一条共同「说明」，按 Enter 或点击输入框内的发送按钮即可添加；选区与说明在同一个界面完成。用「合并」体验按原文顺序拼接选中区块的模拟效果，中间未选的内容会保留。

需要手选范围时，点击左侧拼图图标进入「插件」，打开 Markdown 配置，将「聚焦选取方式」改为「当前选取」。聚焦本身不会自动关注文件，请先添加关注，再生成和应用修改。
